# Security Research Portfolio

Authorized security research on locally deployed open-source software.

## Scope

- Only self-owned local Docker or source-code environments
- No scanning of public instances
- No credential collection
- No destructive database modification
- Responsible disclosure for confirmed vulnerabilities
