# R07 — Outline Security Research

## Target

- Project: Outline
- Version: v1.12.0
- Deployment: Local Docker only
- Research status: In progress

## Scope

- Personal document isolation
- Collection and document permissions
- API key scopes
- OAuth/MCP authorization consistency
- Attachments, revisions, search, and sharing
- Permission revocation behavior

## Method

- Source-code review
- Multi-account positive/negative testing
- API and MCP behavior comparison
- Runtime side-effect verification
- Read-only database confirmation
- Known advisory regression testing

## Safety boundary

No public target was scanned.
No real credentials or personal data were used.
Sensitive evidence and unrepaired findings are not included in this repository.
